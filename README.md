## English

**A transparent logic-based classifier for unfavorable agricultural situations.**

Instituto Superior Politécnico Córdoba · Higher Technical Program in Data Science and AI
**Course:** Logic · **Instructor:** Herrea, Julio · **Year:** 2026
**Team:** Sferco, Emiliano Nicolás · Sukhovetskii, Artem · Tocci, Ivanna

### Overview

A course project (ABP) applying **propositional logic, first-order logic and Boolean algebra** to agricultural estimates data (Secretaría de Agricultura, Ganadería y Pesca, Datos Argentina). The rules are first formalized in logic and then executed on the data, reporting for each case which conditions were met and why (explainability).

### Logic rules

| Symbol | Condition |
|---|---|
| **P** | Non-harvested area rate > 20 %, where rate = (sown − harvested) / sown × 100 |
| **Q** | Regional yield < national yield for the same crop and campaign |
| **R** | 3 or more consecutive production drops for a region and crop |
| **F** | Critical focus: `F = (P ∧ Q) ∨ (P ∧ R) ∨ (Q ∧ R)` (at least two of the three) |

Each production drop is also analyzed for **incidence**: whether harvested area, yield, or both decreased.
Campaigns are compared with the immediately preceding available campaign of the same series (region and crop).

### Repository contents

| File | Description |
|---|---|
| `clasificador_logico.py` | Python script that applies the rules and prints each case's result and explanation |
| `ABP_Logica_Clasificador.xlsx` | Input data and Excel validation (sheets below) |
| `resultado_clasificador.csv` | Output generated by the script on every run |

**Excel sheets**

1. `MiniDataset`: real data sample (oat–Cuyo and lentil–NOA, campaigns 2015/2016 to 2024/2025).
2. `Clasificador`: formula-based computation of P, Q, R, drop streak, critical focus, explanation and incidence. Thresholds (20 % and 3 drops) are in cells `O2` and `O3`.
3. `Validación lógica`: the 8 truth-table combinations checked against real cases, plus a cross-check of all 15 cases against the expected results of the original dataset.

### Requirements

- Python 3.9+
- `pandas` and `openpyxl`

### Usage

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install pandas openpyxl
python clasificador_logico.py ABP_Logica_Clasificador.xlsx
```

An optional second argument sets the output CSV name:

```bash
python clasificador_logico.py ABP_Logica_Clasificador.xlsx results.csv
```

### Output

The script prints three blocks and saves the CSV:

1. Results table per case (rate, P, Q, streak, R, critical focus, incidence).
2. Logical explanation of each classification.
3. Case count per P/Q/R combination.

It finally compares its results with the formulas of the `Clasificador` sheet.

### Validation

The 15 sample cases cover all 8 possible P/Q/R combinations:

| P Q R | Cases | Critical focus |
|---|---|---|
| FFF | 1 | NO |
| FFT | 1 | NO |
| FTF | 3 | NO |
| FTT | 1 | YES |
| TFF | 1 | NO |
| TFT | 1 | YES |
| TTF | 6 | YES |
| TTT | 1 | YES |

(In the script output, `V` = true / verdadero, `F` = false / falso.)
Script results match the Excel formulas and the original dataset's expected values in all 15 cases.

### Descripción

Proyecto ABP que aplica **Lógica de Enunciados, Lógica de Primer Orden y Álgebra de Boole** al análisis de estimaciones agrícolas (Secretaría de Agricultura, Ganadería y Pesca, Datos Argentina). Las reglas se formalizan primero en lógica y luego se ejecutan sobre los datos, indicando para cada caso qué condiciones se cumplieron y por qué (explicabilidad).

### Reglas lógicas

| Símbolo | Condición |
|---|---|
| **P** | Tasa de superficie no cosechada > 20 %, con tasa = (sembrada − cosechada) / sembrada × 100 |
| **Q** | Rendimiento regional < rendimiento nacional del mismo cultivo y campaña |
| **R** | 3 o más caídas consecutivas de producción para una región y un cultivo |
| **F** | Foco crítico: `F = (P ∧ Q) ∨ (P ∧ R) ∨ (Q ∧ R)` (al menos dos de las tres) |

Cada caída de producción se analiza además por **incidencia**: si disminuyó la superficie cosechada, el rendimiento o ambos.
Las campañas se comparan con la campaña disponible inmediatamente anterior de la misma serie (región y cultivo).

### Contenido del repositorio

| `resultado_clasificador.csv` | Salida generada por el script en cada ejecución |

**Hojas del Excel**

3. `Validación lógica`: las 8 combinaciones de la tabla de verdad contrastadas con casos reales, y control cruzado de los 15 casos contra los resultados esperados del dataset.
